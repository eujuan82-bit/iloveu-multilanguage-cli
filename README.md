## ⚡ Instalación Rápida en 1 Paso (Termux / Linux)

Copia y pega este comando en tu terminal para instalar la aplicación y habilitar el comando global `iloveu`:

```bash
curl -sL https://githubusercontent.com | bash
```
# 💖 I Love You - Multi-Language CLI (Termux & PC)

Aplicación interactiva de consola desarrollada en **Python 3** que reúne implementaciones del mensaje universal en 10 lenguajes y empaquetados distintos, incluyendo la gema de Ruby **`eunice_rubi`**.

## 📲 Instalación y Descarga en Termux (Android)

Ejecuta los siguientes comandos en tu terminal de Termux para descargar el repositorio y arrancar la aplicación:

```bash
# 1. Instalar Git y Python
pkg update && pkg install python git -y

# 2. Clonar este repositorio
git clone https://github.com

# 3. Entrar a la carpeta y ejecutar la app
cd TU_REPOSITORIO
python iloveu_app.py
```

## 🚀 Funciones Principales
* **Visor Multi-Lenguaje:** Consulta el código fuente y comandos de ejecución para JavaScript, Python, Java, Rust, Go, Ruby, PHP, C++ y TypeScript.
* **Generador Automático (Opción 11):** Crea automáticamente en tu carpeta local todos los archivos fuente, el `.gitignore` y la estructura completa de la gema **`eunice_rubi`**.
* **Animación en Terminal (Opción 12):** Despliega una animación visual con colores ANSI nativos.
